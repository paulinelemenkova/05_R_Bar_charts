# R Bar Charts (ggplot2)

A collection of R bar-chart scripts built with ggplot2, covering single- and multi-series bars, ordered/ranked bars and grouped comparisons. The example data are agricultural, production and trade statistics for several regions (FAOSTAT, Cuba, Vietnam, Martinique/France).

## Scripts

- 05_Barchart_Cuba.r, 05_Barchart_Vietnam.r, 05_Barchart_Vietnam_export_quant.r: bar charts of national agricultural / export-quantity series (geom_bar / geom_col, ordered categories, fills).

- geom_bar_Mtq_France.r: grouped/【stacked】 bar charts of Martinique-France social and trade data.

- 05_Barchart_24102025.R: a later ggplot2 bar-chart example.

## Methods

- Categorical bar/column charts with ordering, grouping and fill encoding (ggplot2).

## Data

- FAOSTAT and national agricultural / trade CSVs (example data).

## Requirements

- R (>= 4.0); packages: ggplot2, dplyr, readr
